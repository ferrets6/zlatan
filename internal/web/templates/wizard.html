There is one step only you can do.

In March 2025 Google closed the door that let apps read photo libraries — not just this one, every app. So the copy has to start with you asking Google for it. After that, you are done.

{{ if .CanShare }}

When the copy is ready we will ask you to share the Takeout folder with {{ .ShareAccount }} — that is all we need to collect it.

{{ end }}
Why can’t zlatan do this part?

Until March 2025 a program could ask Google for permission to read your photos, and you could grant it on a single screen. Google removed that permission for everyone.

What is left is Google Takeout: a page where you ask Google for a copy of your own library. There is no way for a program to press that button for you — Google does not offer one.

So we do not pretend. You press it, we take it from there, and we will never show you a progress bar for something that is not moving.

Ask Google for a copy of your photos

Five short steps, on Google’s own pages. Nothing here is urgent: this page remembers where you got to, so you can stop and come back tomorrow.

  1. 1 Opened Google Takeout
  2. 2 Chose Google Photos, and nothing else
  3. 3

    Tell Google where to put it

    At the bottom of the Takeout page, press Next step. Google then asks four things. Set them exactly like this:

    Where it goes

    Add to Drive

    How often

    Export once

    File type

    .zip

    File size

    50 GB

    Add to Drive is the one that matters: it puts the copy in your own Google Drive, where we can pick it up without you downloading anything. The large file size just means fewer pieces to keep track of.

    {{ end }} Open Takeout again
  4. 4 Ask Google to start
  5. 5 Share the folder with us

If the page looks different from what we describe, Google has moved something again. Choose the closest thing, or send us the file yourself instead — both routes end in the same place.
